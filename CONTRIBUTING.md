# Contributing

Contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused change and test it.
4. Commit your changes with a clear message.
5. Open a pull request describing what changed and why.

## Bug reports

Include steps to reproduce the problem, the expected result, the actual result, and your operating system or shell.

## Code style

- Keep the Bash script readable.
- Use clear variable names.
- Validate user input.
- Update the README when behavior or usage changes.

By submitting a contribution, you agree that it may be distributed under this project's Apache-2.0 license.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.
