# Simple Interest Calculator

A beginner-friendly Bash script that calculates simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- **Principal**: initial amount of money
- **Rate**: annual interest rate in percent
- **Time**: duration in years

## Requirements

- Linux, macOS, or Windows with Git Bash / WSL

## Run the calculator

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal amount, annual interest rate, and time in years when prompted.

## Example

For principal `1000`, rate `5`, and time `2`, the simple interest is `100.00`.
